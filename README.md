## Line-5-Downtime-Analysis-Interactive-Dashboard
This project analyzes production downtime for June 2026 using key maintenance and operational metrics. It helps identify:

- Machines with the highest downtime
- Major failure modes
- Downtime categories
- Planned vs. unplanned downtime

This project demonstrates practical experience with:
- Data cleaning and transformation
- Data modeling, DAX calculations
- KPI design
- Interactive Power BI dashboards
- Manufacturing analytics
- Equipment reliability analysis
- Maintenance performance reporting

## Reliability Metrics
Measures equipment performance using:

MTTR, MTBF, Trend Analysis, Tracks daily unplanned downtime to identify recurring patterns.

## Interactive Filtering
Users can filter the dashboard by:

Day, Shift, Downtime Type

## Tools Used for this project
Power BI, Power Query, DAX, Excel/CSV (Data Source)

## Some Business Questions Answered
1.  Which machine experiences the highest downtime?
2.  Which failure mode causes the most downtime?
3.  Which downtime category contributes the most production loss?
4.  Which shift records the highest downtime?
5.  Which machines are the most reliable?
6.  How does unplanned downtime change throughout the month?
